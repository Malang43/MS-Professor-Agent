Verified diagnostic defect: providerRequest discards non-success HTTP status/error bodies, so the generic public error hides the distinction. The local fix adds an authorization-code-only wrapper. Public errors and provider retry classifications remain unchanged; redemption is never retried automatically. Mailbox reads, sends and refreshes do not use this wrapper.
